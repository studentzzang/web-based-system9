## explorer 기능 관련 
0~10초 만 분석 
원본 STFT - 0, 7.81, 15.63, 23.44 Hz가 서로 다른 칸
- 주파수 칸 간격 = 샘플레이트 ÷ FFT - 이 간격으로 stft 를 했기 때문 

서버가 - 0, 7.81, 15.63, 23.44 Hz 네 값을 묶어 가장 강한 값 하나를 정해서 하기 때문에 중앙값인 11.72Hz를 사용
DC 오프셋의 영향은 0 Hz 칸에서 강하게 나타나니 11.72Hz부터 노란색 표시  - 10초에서 일정한 치우침과 그 주변의 흔들림이 평균제곱에 기여한 크기를 비교한 값

서버에서 축소- 네 칸 중 가장 큰 파워 하나를 남깁니다. 어느 칸에서 최댓값이 나왔든 대표 좌표는 네 칸의 중심인 11.72 Hz
